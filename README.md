# Kubernetes-Penetration-Testing-and-Benchmarking-with-KubeHunter-KubeBench
This project tests an intentionally vulnerable MLOps ML app on a Minikube Kubernetes cluster in a VM. It uses KubeHunter to find security weaknesses and KubeBench to check CIS benchmark compliance, highlighting hardening needs for secure deployments.
