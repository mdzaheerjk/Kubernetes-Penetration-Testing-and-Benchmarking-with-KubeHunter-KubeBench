# Kubernetes-Penetration-Testing-and-Benchmarking-with-KubeHunter-KubeBench
This project evaluates the security of an MLOps-based machine learning application deployed on a Minikube Kubernetes cluster inside a VM. Intentional vulnerabilities were added to the Deployment and RBAC configurations to simulate real-world weaknesses. KubeHunter was used to detect these security issues
